## 🚀 How to Host on Hostinger (Zero Coding / 60 Seconds)

Since you already have a Hostinger account, you do **NOT** need to struggle with their visual page builder. Follow these simple steps:

### Method 1: Hostinger File Manager (Recommended)
1. Log in to your **Hostinger Control Panel** ([hpanel.hostinger.com](https://hpanel.hostinger.com)).
2. Go to **Websites** $\to$ Click **Manage** next to your domain.
3. In the sidebar/search bar, click **File Manager** (under Files).
4. Double-click the **`public_html`** folder to open it.
5. If there is a `default.php` or placeholder file inside, delete it.
6. Click the **Upload** button (top right icon) and upload all files and folders from this project:
   - `index.html`
   - `company-setup.html`
   - `services.html`
   - `consultation.html`
   - `about.html`
   - `contact.html`
   - `css/` (entire folder)
   - `js/` (entire folder)
   - `assets/` (entire folder)
7. That's it! Visit your domain in your browser and your new website is live immediately with full speed.

## 💻 Local Testing & Preview

To preview the website locally on your computer:
- Simply double-click `index.html` to open it in any browser (Chrome, Edge, Safari, Firefox), or run a lightweight local server:
```bash
# Using Python
python -m http.server 8000

# Or using Node.js
npx serve .
```
Then navigate to `http://localhost:8000` in your web browser.
